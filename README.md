# Skills Guide

Guia de consulta, em português, das skills de design instaladas no Claude: comandos, o que cada um faz e um pedido pronto para copiar.

- Site estático: `index.html` + `data.js` (conteúdo) + `guide.js` (busca, filtros, copiar, modos Day/Night).
- Para adicionar um pacote, edite só `data.js`.
- Visual feito com a [Taste Skill](https://github.com/Leonxlnx/taste-skill) (MIT); os arquivos em `assets/` são do kit dela.

Fontes das skills: Impeccable, Transitions.dev, Agent Skills (Vercel), Taste Skill e Designer Skills Pack.
